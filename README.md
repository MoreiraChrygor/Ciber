# Segurança da Informação
Repositório dedicado a mostrar habilidades e contextos de ferramentas utilizadas na área de cibersegurança 

# Objetivo

- Neste Repositório/Portifólio:

vou elaborar uma estrutura de arquivos que irão dimensionar conteúdos sobre a atuação de cibersegurança sendo eles:

- Ferramentas de Cibersegurança
- recursos usados
- normas de segurança adotadas
- documentação das ferramentas
